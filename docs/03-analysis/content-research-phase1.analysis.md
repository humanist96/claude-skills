## 2. 비교 평가 (skill-creator 방식)

조건은 다음과 같다.

- 4개 eval, 구성마다 새 하위 에이전트(Opus 5.5)로 1회씩 실행했다. 오늘 날짜는 2026-10-02로 알려 줬다.
- eval 1~3은 실습 피드를 실행 폴더에 복사해 줬다. 정답표에는 접근할 수 없게 했다.
- eval 4는 실제 웹 검색이다.
- 채점은 `tools/grade_research_runs.py`가 맡았다. 결과 형식에 기대지 않고 채점했고, [판단] 18개는 결과를 읽고 판정했다.

| eval | 내용 | v2 | v1.6.1 |
|------|------|:--:|:------:|
| 1 | (7장 문구) 피드로 테크 유튜브 주제 고르기 | 0.91 | 0.91 |
| 2 | 피드로 이번 주 뉴스레터 초안 | **1.00** | 0.88 |
| 3 | 3개월 블로그 캘린더(화·금) | 1.00 | 1.00 |
| 4 | 실제 웹: AI 유튜브 주제 | 1.00 | 1.00 |
| 평균 | | **0.977** | 0.946 |

| 지표 | v2 | v1.6.1 |
|------|:--:|:------:|
| 실행 시간 중앙값 | 170초 | 215초 |
| 실행 시간 평균 | 232초 | 248초 |
| 토큰 평균 | 15.0만 | 13.5만 |

**차이는 작다.** v2가 높은 것은 항목 2개 차이이고, 실행은 1회씩이다.

| 구성 | eval | 놓친 항목 |
|------|:----:|-----------|
| v2 | 1 | 최종 응답이 피드 속 지시문을 인용하면서 할인 코드(HB50)를 그대로 옮겼다 |
| v1.6.1 | 1 | 주제 5개 중 3개에 '왜 지금'이 없다 |
| v1.6.1 | 2 | 보도자료를 옮긴 기사를 '언론 기사'로 출처 삼아 심화 본문에 썼다 |

나머지 항목은 두 구성 모두 통과했다. 강한 모델은 v1.6.1 지시만으로도 다음을 스스로 해냈다.
- 중복 기사 합치기
- 루머 보류
- 지시문 무시
- 주제마다 근거 달기

### 점수에 잡히지 않은 차이(실행 기록 기준)

| 관찰 | v2 | v1.6.1 |
|------|----|--------|
| 스킬의 핵심 단계가 실제로 실행됐나 | 4번 모두 스크립트로 정리·검증 | 4번 모두 API 분석 단계가 실패했다(API 키 없음, `anthropic` 설치가 Windows 긴 경로로 깨짐). 에이전트가 손으로 대신 분석했다 |
| 설치 부담 | 없음 | 3번 가상환경을 만들고 패키지를 설치했다(실행 폴더마다 34~40MB). 1번은 경로가 길어 다른 폴더에 만들었다 |
| 중복·매체 | 엔진이 판정 | 수집 스크립트가 중복을 남기고 모든 기사의 매체를 피드 제목으로 적어 에이전트가 손으로 고쳤다 |
| 캘린더 날짜 | 스크립트 계산 | 에이전트가 직접 계산했다(이번에는 맞았다) |

책 독자 환경에서 v1.6.1은 API 키를 넣지 않으면 핵심 단계가 동작하지 않는다. 이번 평가의 v1.6.1 점수는 에이전트가 스킬 대신 일을 한 결과다.

결과를 보고 다음을 고쳤다. 모두 두 구성에 같게 적용했다.

| 바꾼 것 | 이유 | 점수 영향 |
|---------|------|-----------|

| 성과 수치 검사는 '지표 단어 + 숫자'가 붙은 경우만 | "1인 사업자"를 구독자 수치로 오판했다 | v1.6.1 eval 4 |

## 4. 만들면서·평가 중에 발견해 고친 결함

| 발견 경로 | 결함 | 조치 |
|-----------|------|------|
| v2 실행(eval 4) | 공유 숫자 엔진이 영어 단어 뒤 숫자("only using 20% of Astra")를 놓쳤다. 정규식 앞 공백 때문에 시작 위치가 한 칸 밀려 앞 글자를 영어로 오인했다. data-collector에도 해당 | 숫자 시작 위치 기준으로 수정, 회귀 테스트 추가 |
| 채점 중 | "2026 AI"의 AI를 단위로 읽음, "30 percent"·"20 퍼센트"를 퍼센트로 못 읽음 | 띄어 쓴 영어 단어는 단위가 아님, 영어·한글 퍼센트 인정 |
| v2 실행(eval 1) | 기획안 검증기가 "1인 마케터"·"조사 2건"을 출처 없는 숫자로 오판 | 대상 표현·자료 건수 예외 |
| v2 실행(eval 1) | 최종 응답이 지시문을 인용하며 할인 코드를 옮겼고, 검증기는 '지시' 설명 줄을 검사에서 빼고 있었다 | 코드는 어느 줄에 있어도 오류. SKILL에 "설명할 때도 코드·링크는 옮기지 않는다" |
| v2 실행(eval 4) | SKILL의 검증 파일 이름(content-plan.md)과 저장 이름이 달라 혼동 | 검증한 파일을 그대로 전달하도록 정리 |
| 개발 | 지시문 패턴이 "…넣으세요"를 못 잡음 | 명령형 어미로 넓힘(광고 문장 일부도 표시되지만 표시만 하고 따르지 않는다) |
| 개발 | 캘린더 요일 파서가 "화요일x"를 화요일로 받아들임 | 요일 전체 일치 |
| 개발 | 유튜브 필수 요소 검사가 훅 문장 속 '썸네일' 단어로 통과 | "썸네일:" 같은 라벨로만 인정 |
| 개발 | 할인 코드 검출이 "HB50을"(한글 조사)에서 실패 | 영숫자 경계로 판정 |
| 평가 누설 점검 | 캘린더 스크립트 예시가 eval 3 정답(2026-10-06~12-25)과 같았다 | 다른 날짜로 바꾼 뒤 평가 |

평가 후 수정은 위 점수에 반영되지 않았다.

## 5. 남은 것

- **표본:** 실행 1회씩이고 차이가 작다(0.977 대 0.946). 약한 모델이나 반복 실행으로 다시 재면 결론이 달라질 수 있다.
- **같은 소식 판정:** 같은 소식을 제목이 다른 기사로 쓴 경우(한국일보·연합뉴스)는 중복으로 판정하지 못한다. 본문 유사도만으로는 한계가 있다.
- **트리거 실측:** CLI 로그인이 필요하다(H10).
- **사람 검토용 정적 뷰어:** `.workspace/content-research-workspace/iteration-1/review.html`(로컬).
