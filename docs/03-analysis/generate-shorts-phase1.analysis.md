## 2. 비교 평가 (skill-creator 방식)

조건은 다음과 같다.

- 4개 eval, 구성마다 새 하위 에이전트(Opus 5.5)로 1회씩 실행했다. 오늘 날짜는 2026-10-02로 알려 줬다.
- eval 1~3은 실습 영상(과 자막)을 실행 폴더에 복사해 줬다. 정답표에는 접근할 수 없게 했다.
- 두 구성에 같은 환경 규칙을 줬다. 인터넷에서 영상·자막을 받지 않고(받으려던 명령은 `planned_commands.txt`에 적는다), 소프트웨어를 설치하지 않는다.
- eval 2는 faster-whisper가 설치된 파이썬 경로를 요청 문장에 적어 줬다(두 구성 같음).
- 채점은 `tools/grade_shorts_runs.py`가 맡았다. 쇼츠는 `media.probe`로 재고, 구간은 정답표의 구간과 겹침으로 판정했다. [판단] 10개는 프레임과 결과를 보고 판정했다.

| eval | 내용 | v2 | v1.6.1 |
|------|------|:--:|:------:|
| 1 | 강의 영상 + 자막으로 쇼츠 2개 | 1.00 | 1.00 |
| 2 | 자막 없는 강의 영상으로 쇼츠 1개(음성 인식) | 1.00 | 1.00 |
| 3 | 강의 내용을 카드뉴스로 | 1.00 | 1.00 |
| 4 | 뉴스 채널 인터뷰 URL로 쇼츠 3개(권리 미확인) | **1.00** | 0.80 |
| 평균 | | **1.00** | 0.95 |

| 지표 | v2 | v1.6.1 |
|------|:--:|:------:|
| 실행 시간 중앙값 | 234초 | 275초 |
| 실행 시간 평균 | 249초 | 342초 |
| 토큰 평균 | 13.1만 | 15.6만 |

놓친 항목은 하나다. v1.6.1은 eval 4에서 영상 본편 다운로드는 권리 확인 뒤로 미뤘지만, 자막 받기와 후보 생성(`run_pipeline.py --url`)은 권리 확인 전에 하도록 계획했다.

### 점수에 잡히지 않은 차이(실행 기록 기준)

점수 차이가 작은 이유는 v1.6.1 쪽 에이전트가 스킬이 못 하는 부분을 직접 코드로 메웠기 때문이다.

| 관찰 | v2 | v1.6.1 |
|------|----|--------|
| 스킬 밖 코드 | 0개 | 쇼츠·카드를 만든 3번 모두 어댑터를 직접 짰다(4개).<ul><li>`run_local.py`: 로컬 영상 구간 자르기, ffprobe 대체, 폰트 지정</li><li>`stt_local.py`·`local_driver.py`: 음성 인식과 로컬 구동</li><li>`render_cards_win.py`: Windows 폰트 주입</li></ul> |
| 로컬 영상 | 기본 경로 | URL 전용이라 지원하지 않는다 |
| ffmpeg | imageio-ffmpeg로 찾았다 | PATH에 없어 에이전트가 우회했다. 설치 스크립트는 brew·apt 전용이다 |
| 카드 한글 | 정상 | 스킬 그대로는 한글이 네모로 나오고 경고도 없었다 |
| 합성 실패 | (이번 실행에서는 발생 안 함) | 자막·후크 합성이 메모리 부족으로 실패하자 오버레이 없이 다시 만들고 "성공 2개"로 보고했다. 프레임 검수가 없었다면 자막 없는 쇼츠가 전달됐다 |

환경 메모: 평가 중 C 드라이브 여유 공간이 0.2GB여서 페이지 파일이 늘지 못했다(가상 메모리 여유 1.2GB). 두 구성 모두 메모리 할당 실패를 겪었다. v2는 음성 인식 small 모델을, v1.6.1은 x264 인코딩과 small 모델을 다시 시도했다.

## 5. 남은 것

- **표본:** 실행 1회씩이고 객관 항목은 두 구성 모두 거의 만점이다. Opus 5.5 에이전트가 v1.6.1의 빈틈을 직접 코드로 메웠기 때문이다. 약한 모델이나 실제 사용자 세션에서는 차이가 더 클 것으로 보이지만 측정하지 않았다.
- **YouTube URL 경로:** 권리를 확인한 자기 채널 영상으로 실제 다운로드를 해 보지 않았다(평가 규칙상 인터넷 다운로드 금지). 쿠키 정책과 차단 안내는 단위 검사만 했다.
- **출력 프레임률:** 원본 프레임률을 그대로 쓴다. 실습 영상은 5fps라 쇼츠도 5fps다. 일반 영상(24~60fps)에는 문제가 없다.
- **트리거 실측:** CLI 로그인이 필요하다(H10).
- **사람 검토용 정적 뷰어:** `.workspace/generate-shorts-workspace/iteration-1/review.html`(로컬).
