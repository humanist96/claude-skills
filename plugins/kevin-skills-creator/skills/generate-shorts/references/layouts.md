# 세로 레이아웃 선택

원본이 16:9 가로 영상일 때 세로(9:16, 1080x1920)로 바꾸는 방식. 원본 콘텐츠를 보고 고른다.

| layout | 동작 | 언제 쓰나 |
|--------|------|-----------|
| `fit_blur`(기본) | 원본 전체를 폭에 맞춰 넣고 위·아래를 같은 화면의 블러 확대본으로 채움. 아무것도 잘리지 않음 | 화면 녹화, 코드, 슬라이드·강의, 발표, 게임, 표·차트 |
| `crop` | 가운데를 꽉 채우고 좌우를 잘라냄 | 인물이 화면 가운데에 있는 토킹헤드·인터뷰·브이로그 |
| `fit` | 단색(검정) 레터박스 | 배경을 깔끔하게 두고 싶을 때 |

확신이 없으면 `fit_blur`. 강의·코드·화면 녹화를 `crop`으로 처리하면 좌우가 잘려 못 읽는다.

## 원본에 자막이 구워진 영상

방송·예능 클립처럼 화면 아래에 자막이 이미 있으면:
- 인물 중심이라도 `fit_blur`(crop은 원본 자막과 B롤을 좌우로 자른다)
- `highlights.json`의 `subtitles`를 `[]`로 두어 이중 자막을 피하고 후크만 얹는다
- 판단이 어려우면 구간 프레임을 한 장 뽑아 본다:
  `ffmpeg -ss <초> -i <영상> -frames:v 1 <W>/check.png` (ffmpeg 경로는 `python scripts/_vendor/media.py --check`)

## 후크 오버레이

검은 인트로 카드 대신 본편 첫 2.5초 위에 후크 문구를 얹는다. 첫 1~2초가 정지된 검은 화면이면 시청자가 바로 넘긴다.
설정: `templates/config_template.yaml`의 `hook_overlay`·`hook_duration`·`hook_font_size`. 인트로·아웃로 카드는 기본 꺼짐.
