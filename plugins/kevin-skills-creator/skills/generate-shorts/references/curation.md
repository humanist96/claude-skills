# 하이라이트 큐레이션 (3단계 — 품질의 핵심)

`<W>/candidates.json`(규칙 점수로 추린 후보)과 `<W>/transcript_timestamped.txt`(전체 대본)를 읽고 `<W>/highlights.json`을 쓴다.
규칙 점수는 감정 단어 개수를 셀 뿐 내용을 이해하지 못한다. 점수 순이 아니라 내용을 읽고 고른다.

## 고르는 기준

1. **독립성**: 앞뒤 맥락 없이 그 구간만 봐도 이해된다. 목록 순서말("세 번째," "다음으로")로 시작하면 시작점을 그 말 뒤로 옮기거나, 옮길 수 없으면 화면 자막에서라도 뺀다(음성에는 남는다는 점을 사용자에게 알린다)
2. **후크**: 첫 1~2문장이 궁금증을 만든다(질문, 반전, 강한 주장, 구체적 숫자)
3. **완결성**: 구간 안에서 작은 결론이 나온다
4. **다양성**: 고른 쇼츠끼리 주제가 겹치지 않는다

쓰지 않는 구간: 인사·구독 요청, 주제와 무관한 잡담, 앞 내용을 요약하는 마무리, 다음 영상 예고.
개수는 요청을 따르고, 요청이 없으면 기준을 만족하는 구간만(보통 영상 10분당 1~2개). 억지로 채우지 않는다.

## 경계 조정

후보의 start·end는 참고값이다. 대본에서 문장이 시작되는 지점에서 시작해 결론 문장이 끝나는 지점에서 끝내도록 초 단위로 조정한다(15~60초).
`validate_highlights.py --transcript`가 문장 경계와 1초 넘게 어긋나면 경고한다.

## 제목·후크

- 음성인식 오류는 문맥으로 고친다(예: "7발1 2입니다" → 실제 발화). 고친 내용은 최종 응답에 적는다
- `title`: 내용 요약형, 28자 이내
- `hook`: 화면 위에 크게 얹히는 문구, 20자 이내. 낚시가 아니라 호기심 유발이며, 영상에 없는 숫자·주장을 쓰지 않는다

## 자막 재구성(`subtitles`)

자동자막의 롤링 파편을 문장 단위로 다시 쓴다. 생략하면 원본 자동자막이 그대로 들어가 중복·오인식이 화면에 보인다.
- 시간은 **구간 시작 기준 상대 초**(start=0.0이 구간 시작). 마지막 자막은 구간 길이를 넘지 않는다
- 한 줄은 2~5초, 두 줄 이내(40자 이내), 실제 말 타이밍과 대략 맞게
- 간투사("어", "음") 제거, 인식 오류 교정
- 원본 화면에 자막이 이미 구워져 있으면 `"subtitles": []`로 두어 이중 자막을 피한다

## 스키마

```json
[
  {
    "index": 1,
    "start": 1065.1,
    "end": 1096.5,
    "title": "스피커 임베딩이 목소리를 결정한다",
    "hook": "AI가 목소리를 배우는 법",
    "reason": "화자 임베딩 개념이 독립적으로 설명되고 결론까지 이어짐",
    "hashtags": ["음성합성", "AI"],
    "subtitles": [
      {"start": 0.0, "end": 3.5, "text": "화자 테이블에서 스피커 정보를 가져옵니다"},
      {"start": 3.5, "end": 7.0, "text": "이걸 입력 임베딩에 넣어 주면"}
    ]
  }
]
```

`hashtags`는 선택이다. 설명 문구에 `#shorts #쇼츠` 뒤로 붙는다. 없으면 제목의 첫 단어 하나만 태그가 된다.

인코딩 전에 검사한다: `python ${CLAUDE_SKILL_DIR}/scripts/validate_highlights.py <W>/highlights.json --source <W>/source.json --transcript <W>/transcript.json`
